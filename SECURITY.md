# Security policy

This repository is the source of https://yafirasyad.github.io, a static site with no backend, forms or user data.

## Reporting a vulnerability

Email **yafirasyadd@gmail.com** with the URL, what you found and how to reproduce it.
Please do not open a public issue for security problems.

The same contact is published at https://yafirasyad.github.io/.well-known/security.txt.

## Scope

In scope: anything served from `yafirasyad.github.io` and the contents of this repository.

Out of scope: GitHub's own platform and infrastructure (report those to GitHub), missing HTTP headers
that GitHub Pages does not allow site owners to set, and automated scanner output without a working impact.
